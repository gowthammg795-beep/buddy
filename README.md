# 🤖 My Buddy V1

My Buddy is an intelligent robotic assistant built around the ESP32.

The project combines embedded systems, robotics, sensors, audio processing and wireless communication to create an interactive smart robot.

🚀 Features

- 🤖 ESP32-based control
- 🎤 Voice input using INMP441 microphone
- 🔊 Audio output using MAX98357A
- 🚗 Motor control and movement
- 📡 Wireless communication
- 📏 Ultrasonic obstacle detection
- 👁️ Motion detection
- 🖥️ OLED status display
- 🎮 Manual and autonomous control
- 🔧 Modular sensor architecture
  
🛠️ Technologies

- ESP32
- Arduino / Embedded C++
- Sensors & Actuators
- I2C
- I2S Audio
- Wi-Fi
- AI APIs
- Robotics

## 🎯 Goal

To develop a compact, interactive robotic companion that combines embedded hardware with AI and real-world sensing.
